# 부천의 나라 🏘️

부천 동네끼리 싸우는 귀여운 멀티플레이 RPG (바람의나라 느낌). 브라우저에서 바로 플레이, 회원가입 없이 **이름 + 비밀번호**만.

## Render 무료 배포

1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 올리지 않아도 됨).
2. **데이터 저장용 무료 DB 만들기 (중요)**
   Render 무료 서버는 15분 동안 아무도 없으면 잠들고, 다시 켜질 때 파일이 초기화돼서 계정이 날아갑니다.
   그래서 무료 Postgres를 하나 연결하는 게 좋아요.
   - https://neon.tech 가입 → 프로젝트 생성 → **Connection string** 복사 (`postgresql://...` 로 시작)
   - (Supabase 무료 DB도 됩니다. Render 자체 무료 Postgres는 30일 뒤 만료돼요)
3. https://render.com → **New + → Web Service** → GitHub 저장소 선택
   - Runtime: Node · Build: `npm install` · Start: `npm start` · Plan: **Free**
   - Environment 에 추가:
     - `DATABASE_URL` = 2번에서 복사한 주소
     - `ADMIN_PW` = 관리자 비밀번호 (이름 `관리자`로 이 비밀번호를 쓰면 관리자 모드)
   - (또는 **New + → Blueprint** 로 저장소를 고르면 `render.yaml` 설정이 자동 적용돼요)
4. 배포가 끝나면 `https://xxxx.onrender.com` 주소로 접속해서 친구들한테 공유!

> 잠든 서버는 첫 접속 때 깨어나는 데 30초~1분 걸려요.

## 게임 내용
- **진영**: 상동(빨간 망토·공격+8%) / 중동(파란 백팩·방어+15%) / 원종(새싹·HP+12%) / 역곡(헤드폰·이속+10%) / 소사(고양이귀·MP+20%·골드+15%). 동네마다 기본 옷 색과 장신구가 달라요. 다른 진영은 공격 가능, 죽으면 가방 아이템 1~3개를 바닥에 떨어뜨려 다른 사람이 주울 수 있음 (장착 장비는 안전). 마을 안전지대는 PvP 불가.
- **직업**: 초보자로 시작 → Lv.10에 1차 직업 선택
  박병문(하프마라톤 러너·핵주먹) · 윤태정(턱공격) · 이소현(니온앤니온 범위 힐+버프) · 이종혁(티\~원 범위 공격력 버프) · 이규태(운전병 이속) · 김도현(도리스타 범위 스턴) · 정석환(정스카니즘 댄스 셀프스턴+체력회복) · 지영훈(헬스 쿨타임 없는 회복) · 이진우(어\~승현 범위 둔화+본인 가속) · 김병준(해녀 만능 버프) · 김명진(아스날 축구팀 근거리 축구공)
  직업마다 Lv10 / 15 / 20 스킬 3개.
- **등급**: 일반 · 고급 · 희귀 · 영웅 · 에픽 · **전설(노란색, 히든)**. 좋은 등급일수록 드랍률 낮음.
- **히든 장비**: 영웅 이상 장비가 특정 접두사+종류 조합(예: 황금+프라이팬)으로 나오면 노란 전설로 변신. 에픽 3개 합성으로도 노릴 수 있음.
- **강화**: 무한 강화. +3부터 실패 확률, +5부터 파괴 확률. 보호 주문서로 파괴 방지. 주문서는 몬스터 드랍/상점/퀘스트 보상.
- **장비**: 무기/투구/갑옷을 끼면 캐릭터 그림에 그대로 반영 (무기 모양·등급 색·강화 반짝임).
- **보스**: 상동역 술집거리에 거대한 테니스 괴물 **김승현**(테니스공 원거리 공격, 약해서 Lv10도 솔로 가능). 부천 들판에 흰색 말티즈 **밥풀이** — 윤태정 직업이 다가가면 영구 탈것이 됨(이동속도 +35%). 김포최명순은 이소현을 발견하면 쫓아가서 잔소리 후 혼자 술 먹고 꽈당. 사냥터마다 약 1시간에 한 번 등장 (전체 공지), 보스마다 범위 스킬. 부천시청: 잘생긴 쌍둥이 **천현창 & 김도현**(도리스타), 무서운 할머니 **김포최명순**(마이크 샤우팅 스턴 + 끝없는 잔소리). 원종 지하던전: 하복 입은 드라큘라 **박휘석**(엑소시즘 볼펜, 정석환 직업에게 2.5배 데미지)
- **레이드**: 부천 들판 가운데 포탈 → ⚔️ 보스 대기실 → 안내원에게 '보스 참여' → 20초 뒤(또는 바로 출발) 참여자 전원 입장, 경험치는 참여자끼리 나눔. 한 번에 한 팀만.
  - Lv10 버섯브로콜리: 버섯+브로콜리 → 합체 후 점프 찍기(경고 칸 피하기), 체력이 줄면 작아짐
  - Lv30 티라노: 불꽃 갑옷(보호막) → 파란 냉각 발판을 모두 밟으면(10초 유지) 12초 그로기, 피해 1.5배. 2페이즈 메가 티라노가 찢고 나오며 화산 폭발로 바닥 곳곳이 용암(밟으면 지속 피해)
  - Lv40 심연의 문어왕 (3인 필수): 목숨 4개(3번 부활). 보호막은 노란 등대 발판 3개를 3명이 동시에 2초 밟아야 깨짐. 먹물 장판, 촉수 줄공격(촉수는 20초 뒤 부활), 소용돌이, 3페이즈부터 해일(틈으로 피하기), 마지막 목숨에 바닥 붕괴
  - Lv70 시계탑 마왕 (3인 필수): 목숨 5개(4번 부활, 시간 되감기). 톱니 발판 3인 동시 밟기, 회전 시곗바늘 레이저, 시한폭탄(붙은 사람은 떨어지기), 운명의 일격(노란 원에 3명 이상 모여 나눠 맞기, 실패 시 전원 피해 + 회복), 3페이즈부터 분신 3체, 4페이즈부터 안전 구역 하나뿐, 마지막에 바닥 붕괴
  - Lv50 석상왕: 팔 8개(본체 무적) → 보호막: 석상왕이 말하는 색깔 순서대로 발판 밟기(틀리면 처음부터 + 충격파) → 그로기 → 분노 3페이즈: 바닥이 바깥부터 무너지고 화면이 어두워짐, 체력 50%에서 한 번 더 붕괴. 클리어 시 보상이 맵 전체에 흩어지고 '석상왕의 왕관'(공격+120/방어+40/HP+800) 확정
- **맵**: 부천 들판(Lv1~7, 가운데 보스 포탈) — 5개 동네 마을(안전지대)이 위·대각선에 있고 마을 밖은 바로 사냥터 + 진영전 → 상동역 술집거리(Lv8~13) → 디에이트 헬스장(Lv12~17) → 부천시청(Lv15~21) → 춘의동굴(Lv17~24) → 원종 지하던전(Lv25+). 두 번째 맵부터는 입구 왼쪽에 같은 모양의 안전지대. 술집거리 위쪽 포탈은 ♨️ 사우나 세이브존
- **채팅**: 그냥 입력 = 같은 맵 (머리 위 말풍선) · `!내용` = 전체 · `/w 이름 내용` = 귓속말
- **아이템 포커**: 다른 사람을 클릭 → 포커 신청 → 서로 아이템 하나씩 걸고 5장 드로우 포커. 이긴 사람이 상대 아이템을 가져감.
- **퀘스트**: NPC 스토리 퀘스트 12개 (이장님 → 포차 이모 → 헬스장 관장님 → 시장 비서 → 광부 할아버지 → 수상한 점술가) + 사우나 세신사 반복 퀘스트. 머리 위 ! = 새 퀘스트, ? = 완료 보고
- **냉동참치 (필드 보스)**: 레이드를 깨면 참여자 전원에게 재료 1개 (Lv10 합체 포자 · Lv30 메가 공룡 비늘 · Lv40 문어왕의 먹물 · Lv50 분노의 핵 · Lv70 시간의 톱니). 가방 → 🧪 제작에서 합체 포자×2 + 메가 공룡 비늘×2 + 문어왕의 먹물×1 + 분노의 핵×1 + 50만G로 **냉동참치 보따리** 제작. 사냥터에서 사용하면 그 자리에 냉동참치 보스(HP 45만, 얼음 꼬리치기 스턴) 등장(서버에 1마리만). 잡으면 [전설] **대형 냉동참치** 확정 — 공격+160/HP+600, 캐릭터가 거대한 참치를 들고 평타가 반경 3칸 전체 공격.
- **드랍**: 좋은 장비는 매우 드묾 (일반 몹 장비 4%, 영웅 이상은 수천 마리에 하나). 보스는 장비 1개(25% 확률로 2개), 레이드 보상 개수도 줄임. 몬스터를 잡으면 골드·장비·재료가 바닥에 떨어짐 → F키(폰은 줍기 버튼)로 줍기. 20초 동안은 잡은 사람만 주울 수 있음

## 무한장 (관리자 이벤트)
관리자 창 → 🔥 무한장 시작: 관리자 제외 접속자 전원이 무한장 맵으로 이동, 3·2·1 카운트 후 진영 상관없이 싸움. 18초마다 자기장(바깥부터 무너짐) 축소, 마지막 1명에게 골드(참가자 수 × 10만, 최소 30만).

## 관리자 모드
이름 **관리자** + 관리자 비밀번호로 로그인하면 관리자 모드. Render 환경변수 `ADMIN_PW`를 설정하면 그 비밀번호로 바뀜.
상단 👑 버튼(또는 P키)으로 관리자 창: 무적 / 한방 / 초고속 / 완전회복 / 보스 소환(종류 선택) / 몬스터 소환 / 맵 몬스터 제거 / 순간이동 / 레벨·골드·주문서·포션 / 등급별 장비 지급(전설 히든 포함) / 직업·진영 변경.
맵 ID: sangdong, jungdong, wonjong, yeokgok, sosa, pub(술집거리), sauna(사우나), gym(헬스장), hall(시청), cave1(춘의동굴), cave2(원종 지하던전)

## 직업 추가하는 법
`jobs.js` 에 같은 모양으로 한 항목 추가하면 끝. `tier: 1` 이면 1차 직업 선택 화면에 자동으로 나옵니다.
스킬 종류(`k`): `aoe`(내 주변) `shot`(단일) `multi`(연타) `aoeT`(대상 위치 폭발) `dash`(돌진) `abuff`(범위 아군 회복/버프) `sbuff`(자기 버프) `adebuff`(범위 적 둔화)
옵션: `stun`(기절 ms) `slow` `heal`(회복 비율) `atk` `def` `spd`(배율) `dur`(지속 ms)
