# 부천의 나라 🏘️

부천 동네끼리 싸우는 귀여운 멀티플레이 RPG (바람의나라 느낌). 브라우저에서 바로 플레이, 회원가입 없이 **이름 + 비밀번호**만.

## Render 무료 배포

1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 올리지 않아도 됨).
2. **데이터 저장용 무료 DB 만들기 (중요)**
   Render 무료 서버는 15분 동안 아무도 없으면 잠들고, 다시 켜질 때 파일이 초기화돼서 계정이 날아갑니다.
   그래서 무료 Postgres를 하나 연결하는 게 좋아요.
   - https://neon.tech 가입 → 프로젝트 생성 → **Connection string** 복사 (`postgresql://...` 로 시작)
   - (Supabase 무료 DB도 됩니다. Render 자체 무료 Postgres는 30일 뒤 만료돼요)
3. https://render.com → **New + → Web Service** → GitHub 저장소 선택
   - Runtime: Node · Build: `npm install` · Start: `npm start` · Plan: **Free**
   - Environment 에 추가:
     - `DATABASE_URL` = 2번에서 복사한 주소
     - `ADMIN_NAME` = 관리자로 쓸 캐릭터 이름 (선택)
   - (또는 **New + → Blueprint** 로 저장소를 고르면 `render.yaml` 설정이 자동 적용돼요)
4. 배포가 끝나면 `https://xxxx.onrender.com` 주소로 접속해서 친구들한테 공유!

> 잠든 서버는 첫 접속 때 깨어나는 데 30초~1분 걸려요.

## 게임 내용
- **진영**: 상동 / 중동 / 원종 / 역곡 / 소사. 다른 진영은 공격 가능, 죽으면 가방 아이템 1~3개를 바닥에 떨어뜨려 다른 사람이 주울 수 있음 (장착 장비는 안전). 마을 안전지대는 PvP 불가.
- **직업**: 초보자로 시작 → Lv.10에 1차 직업 선택
  박병문(핵주먹) · 윤태정(턱공격) · 이소현(니온앤니온 범위 힐+버프) · 이종혁(티~원 범위 공격력 버프) · 이규태(운전병 이속) · 김도현(도리스타 범위 스턴) · 정석환(정스카니즘 댄스 셀프스턴+체력회복) · 지영훈(헬스 쿨타임 없는 회복) · 이진우(어~승현 범위 둔화+본인 가속) · 김병준(해녀 만능 버프) · 김명진(아스날 축구팀 근거리 축구공)
  직업마다 Lv10 / 15 / 20 스킬 3개.
- **등급**: 일반 · 고급 · 희귀 · 영웅 · 에픽 · **전설(노란색, 히든)**. 좋은 등급일수록 드랍률 낮음.
- **히든 장비**: 영웅 이상 장비가 특정 접두사+종류 조합(예: 황금+프라이팬)으로 나오면 노란 전설로 변신. 에픽 3개 합성으로도 노릴 수 있음.
- **강화**: 무한 강화. +3부터 실패 확률, +5부터 파괴 확률. 보호 주문서로 파괴 방지. 주문서는 몬스터 드랍/상점/퀘스트 보상.
- **장비**: 무기/투구/갑옷을 끼면 캐릭터 그림에 그대로 반영 (무기 모양·등급 색·강화 반짝임).
- **보스**: 사냥터마다 약 1시간에 한 번 랜덤 색깔/장식의 보스 등장 (전체 공지).
- **맵**: 동네 마을(Lv1~6) → 원미산(Lv8~14) → 춘의 동굴(Lv15~20) → 심곡 지하던전(Lv25+)
- **채팅**: 그냥 입력 = 같은 맵 (머리 위 말풍선) · `!내용` = 전체 · `/w 이름 내용` = 귓속말
- **아이템 포커**: 다른 사람을 클릭 → 포커 신청 → 서로 아이템 하나씩 걸고 5장 드로우 포커. 이긴 사람이 상대 아이템을 가져감.
- **퀘스트**: 처치/재료 수집 퀘스트, 경험치·골드·주문서·장비 보상. 반복 퀘스트 있음.

## 조작
방향키/WASD 이동 · Space 공격 · 1~4 스킬 · Z/X 포션 · I 가방 · E 장비 · Q 퀘스트 · B 상점 · J 직업 · Enter 채팅
모바일은 화면 버튼으로 조작.

## 관리자 명령 (ADMIN_NAME 캐릭터로 채팅창에 입력)
`/boss` 보스 소환 · `/lv 숫자` 레벨 설정 · `/gold` 골드 10만 · `/scroll` 주문서 · `/go 맵ID` 이동 (sangdong, jungdong, wonjong, yeokgok, sosa, wonmi, cave1, cave2) · `/give 이름` 보스급 장비 지급

## 직업 추가하는 법
`jobs.js` 에 같은 모양으로 한 항목 추가하면 끝. `tier: 1` 이면 1차 직업 선택 화면에 자동으로 나옵니다.
스킬 종류(`k`): `aoe`(내 주변) `shot`(단일) `multi`(연타) `aoeT`(대상 위치 폭발) `dash`(돌진) `abuff`(범위 아군 회복/버프) `sbuff`(자기 버프) `adebuff`(범위 적 둔화)
옵션: `stun`(기절 ms) `slow` `heal`(회복 비율) `atk` `def` `spd`(배율) `dur`(지속 ms)
